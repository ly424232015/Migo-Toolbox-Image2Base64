常见问题

什么是 Base64 编码？ ▼

Base64 是一种将二进制数据（如图片）表示为 ASCII 字符串的编码方案。它通常用于将图片直接嵌入 HTML、CSS 或 JSON 中，而无需单独的文件。

使用这个工具安全吗？ ▼

绝对安全！此工具完全在您的网页浏览器中运行。您的图片不会上传到任何服务器。所有处理都在您的设备上本地进行，确保完全的隐私和安全。

支持哪些图片格式？ ▼

我们支持所有常见的图片格式，包括 PNG、JPEG/JPG、GIF（包括动图）、BMP、WebP、SVG、TIFF 和 ICO。除非您选择其他格式，否则输出将保持原始格式。

如何在 CSS 中使用 Base64？ ▼

您可以在 CSS 中使用 background-image 属性来使用 Base64：background-image: url(data:image/png;base64,YOUR_BASE64_STRING)。在输出中选择「CSS」选项卡以获取可直接使用的 CSS 代码。
